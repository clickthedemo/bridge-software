# Bridge Phase 2 — Journey Maps and Acceptance Criteria

**Against:** Phase 2 routes on Trusted Current review build

## Journey A — First-time discovery
1. Open Home. 2. Name the four spaces. 3. Open each in one click.  
**Pass:** Consistent labels; product utility in first viewport; no single oversized hero hides navigation.

## Journey B — Feed comparison
1. Open Community News. 2. Scan News grid. 3. Switch to Classic. 4. Confirm same items + selected state. 5. Repeat ~390px width.  
**Pass:** Both layouts work; selection clear; mobile usable.

## Journey C — Targeted promotion
1. Open Create. 2. Select Promotion. 3. Upload valid PNG/JPEG/WebP/PDF ≤25MB. 4. Select audiences. 5. Enable protected detail → Adults 21+ removed. 6. Publish blocked if no eligible audience.  
**Pass:** File rules + audience guard behave as specified.

## Journey D — Business home base
1. Open My Profile. 2. Complete the mandatory first-login or monthly contact review. 3. Review sales + accounting contacts in B2B. 4. Confirm cycle. 5. Switch Public → protected contacts hidden; no EIN.
**Pass:** Cadence clear; Public strips protected data.

## Journey E — Nationwide discovery + favorites
1. Open Explore. 2. Confirm 50 states + D.C. 3. Filter; count updates. 4. State with no samples shows honest empty language. 5. Favorite + Favorites only. 6. Introduction is request, not auto-disclosure.  
**Pass:** Filters, favorites, coverage honesty.

## Regression
- No horizontal overflow at ~1440×900 and ~390×844 on primary routes.
- Provisional labeling visible on locked staging builds.
- Illustrative data never claimed as live production metrics.
