# Bridge — Design (Phase 2 review)

Modern Network (Connected) is the default review direction. The approved review atmosphere is dark and purple throughout: night canvas `#09060D`, purple action `#6500A8`, violet accent `#B983FF`, coral signal `#FF7968`, and tinted dark surfaces `#17111E` and `#23182D`.

The unified URL `https://bridge-connected-signal.netlify.app` stays on that purple direction. Trusted Current navy/teal remains available at `https://bridge-preview-current.netlify.app` and via the in-app switcher on unlocked builds.

Tokens live in `app/globals.css`. Default `:root` and `data-theme="network"` share the Connected palette. The home and product routes use the same dark environment so entering the prototype does not break the approved brand atmosphere.

Phase 2 surfaces stay instituted: compact home hierarchy, news grid/classic, create multi-audience, Public/B2B profile, explore filters, plus the Phase 1 directory/join/profile/dashboard/admin/contact/search work. This is a visual restore of Connected purple on that product, not a different app.
